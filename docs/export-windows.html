Export NaviPOS pro Windows

Postup vytvoření portable pokladního systému se zabudovaným Java runtime, který lze na cílovém počítači spustit bez instalace JDK nebo JRE.

Rychlý přehled

Počítač pro sestaveníWindows 10/11, internet a přístup ke zdrojovému kódu.
VýstupSložka s NaviPOS.exe, aplikací a vlastním Java runtime.
Cílový počítačNepotřebuje JDK ani JRE. Potřebuje přístup k MySQL a nakonfigurovanou tiskárnu.
Důležité: Windows balíček musí být sestaven na Windows. Balíček vytvořený na macOS nebo Linuxu nelze použít jako Windows aplikaci.

1. Požadavky pro sestavení

PožadavekÚčel
Windows 10 nebo Windows 11jpackage vytváří platformně závislý spouštěč.
Zdrojový kód NaviPOSRepozitář musí obsahovat gradlew.bat a modul navisoft.
Internet při prvním sestaveníGradle může stáhnout JDK 25, Gradle distribuci a knihovny.
JDK 25Je potřeba pouze pro sestavení. Gradle toolchain jej může obstarat automaticky.
Koncový uživatel JDK nepotřebuje. Výsledný adresář obsahuje vlastní Java runtime ve složce runtime.

2. Sestavení aplikace

Otevřete PowerShell nebo Windows Terminal v kořenové složce repozitáře, kde se nachází soubor gradlew.bat.

2.1 Kontrola zdrojového kódu

git status

Před vydáním zkontrolujte, že sestavujete správnou větev a že v repozitáři nejsou nechtěné lokální změny.

2.2 Testy a vytvoření portable obrazu

.\gradlew.bat clean :navisoft:test :navisoft:jpackage

Úloha provede čisté sestavení, spustí testy a následně použije JDK nástroj jpackage.

2.3 Výsledná struktura

navisoft\build\jpackage\NaviPOS\
├── NaviPOS.exe
├── app\
│   ├── navisoft-11.0.0-SNAPSHOT-plain.jar
│   └── ostatní knihovny .jar
└── runtime\
    └── zabudovaný Java runtime
Nekopírujte pouze NaviPOS.exe. Ke spuštění jsou nutné také celé složky app a runtime.

3. Vytvoření distribučního ZIPu

Po úspěšném sestavení vytvořte ZIP celé složky NaviPOS:

Compress-Archive `
  -Path .\navisoft\build\jpackage\NaviPOS `
  -DestinationPath .\navisoft\build\jpackage\NaviPOS-windows-x64-11.0.0.zip `
  -Force

Doporučené pojmenování:

NaviPOS-windows-x64-11.0.0.zip

3.1 Kontrolní součet

Pro kontrolu neporušenosti vytvořte SHA-256:

Get-FileHash `
  .\navisoft\build\jpackage\NaviPOS-windows-x64-11.0.0.zip `
  -Algorithm SHA256

Výsledný hash uložte společně s vydaným ZIPem.

4. Konfigurace databáze a EET

Portable balíček obsahuje aplikaci a Javu, nikoli MySQL server. Cílový počítač musí mít přístup k existující databázi NaviPOS.

4.1 Proměnné prostředí

Pro jednorázové testovací spuštění nastavte proměnné v PowerShellu:

$env:NAVISOFT_DB_URL = "jdbc:mysql://localhost:3306/pricetags?useUnicode=true&characterEncoding=UTF-8&serverTimezone=Europe/Prague"
$env:NAVISOFT_DB_USERNAME = "navisoft"
$env:NAVISOFT_DB_PASSWORD = "doplnit-bezpecne-heslo"
$env:NAVISOFT_FLYWAY_ENABLED = "true"
$env:NAVISOFT_CASHDESK_PIN = "doplnit-pin"

.\navisoft\build\jpackage\NaviPOS\NaviPOS.exe

Takto nastavené hodnoty platí jen pro aktuální okno PowerShellu.

4.2 Volitelná konfigurace EET

$env:NAVISOFT_EET_ENVIRONMENT = "playground"
$env:NAVISOFT_EET_CERTIFICATE_PATH = "C:\NaviPOS-data\certifikaty\eet.p12"
$env:NAVISOFT_EET_CERTIFICATE_PASSWORD = "doplnit-bezpecne-heslo"
Bezpečnost: Nevkládejte databázové heslo, PIN ani heslo k certifikátu do zdrojového kódu nebo distribučního ZIPu. Produkční certifikát ukládejte mimo adresář aplikace s omezenými přístupovými právy.

4.3 Databázové předpoklady

  • MySQL server je spuštěný a dostupný.
  • Databáze pricetags a její základní tabulky již existují.
  • Databázový uživatel má práva číst a zapisovat provozní data.
  • Při prvním spuštění má právo vytvořit Flyway tabulku a nové migrační objekty.
Historický soubor src/main/resources/sql/Database.sql není kompletní instalační migrace pro prázdnou databázi. Nový počítač proto nelze připravit pouze spuštěním portable ZIPu.

5. Předání a spuštění u zákazníka

  1. Předejte soubor NaviPOS-windows-x64-11.0.0.zip.
  2. ZIP rozbalte například do C:\NaviPOS. Aplikaci nespouštějte přímo uvnitř ZIPu.
  3. Nakonfigurujte databázové připojení a případně EET.
  4. Připojte a ve Windows nastavte pokladní tiskárnu jako výchozí.
  5. Spusťte C:\NaviPOS\NaviPOS.exe.

Na cílovém počítači se neinstaluje JDK ani JRE.

6. Kontrola výsledku

Finální balíček ověřte na čistém Windows počítači nebo virtuálním stroji bez nainstalované Javy.

  • ZIP lze bez chyby rozbalit.
  • NaviPOS.exe se spustí bez systémového JDK/JRE.
  • Aplikace se připojí k nakonfigurované MySQL.
  • Funguje přihlášení a načtení produktů.
  • Lze vytvořit, uložit a znovu načíst účtenku.
  • Funguje tisk na cílové pokladní tiskárně a české znaky.
  • Záloha databáze funguje s nakonfigurovaným mysqldump.exe.
  • EET Playground funguje s testovacím certifikátem, pokud je EET používáno.
  • Aplikace se spustí i z cesty obsahující mezery a české znaky.
  • Při nedostupné databázi je chyba diagnostikovatelná.

7. Časté problémy

ProblémPravděpodobná příčina a řešení
gradlew.bat nelze spustitPříkaz není spuštěn z kořene repozitáře nebo chybí právo spouštět soubor.
Gradle nemůže stáhnout JDK či knihovnyZkontrolujte internet, proxy, firewall a přístup k Maven Central a Gradle službám.
Aplikace se nepřipojí k databáziOvěřte URL, port 3306, uživatele, heslo, firewall a existenci databáze.
Po přesunu nefunguje aplikaceByl přesunut pouze EXE. Přesuňte vždy celý adresář NaviPOS.
Nefunguje tiskVe Windows není výchozí tiskárna nebo chybí odpovídající ovladač.
Nefunguje záloha databázeAplikace potřebuje dostupný program mysqldump.exe a správně uloženou cestu.
Windows zobrazí bezpečnostní upozorněníSpouštěč není digitálně podepsaný. Pro zákaznickou distribuci použijte firemní code-signing certifikát.

8. Doporučení před produkčním vydáním

  • Automatizovat vytvoření Windows ZIPu přímo v Gradle.
  • Doplnit kvalitní Windows ikonu přes parametr jpackage --icon.
  • Vytvořit korektní Flyway migrace pro kompletní inicializaci nové databáze.
  • Nahradit relativní pracovní soubor file.txt bezpečným dočasným souborem.
  • Doplnit uživatelsky srozumitelnou chybu při nedostupné databázi nebo tiskárně.
  • Nastavit logování do stabilního adresáře, například %LOCALAPPDATA%\NaviPOS\logs.
  • Před distribucí podepsat Windows spouštěč a evidovat SHA-256 vydaného ZIPu.
